# Производство фанеры - АО «Красный якорь»

## О проекте

Данный проект разработан в рамках производственной практики по ПМ.11 «Разработка, администрирование и защита баз данных». 

Проект представляет собой информационную систему для автоматизации учёта производства фанеры на предприятии АО «Красный якорь». Система позволяет отслеживать полный цикл производства: от приёмки круглого леса до отгрузки готовой фанеры покупателю.

## Технологический стек

| Компонент | Технология |
|-----------|------------|
| База данных | Microsoft SQL Server |
| Язык запросов | T-SQL |
| Клиентское приложение | WPF (.NET Framework 4.8) |
| Язык программирования | C# |
| Доступ к данным | ADO.NET |
| Система контроля версий | Git / GitHub |


### 1. База данных

- 14 таблиц, нормализованных до 3НФ
- Внешние ключи для обеспечения ссылочной целостности
- Индексы для оптимизации запросов
- Более 1500 тестовых записей

### 2. Роли пользователей

| Роль | Возможности |
|------|-------------|
| **Администратор** | Управление пользователями, ролями, резервное копирование, просмотр отчётов |
| **Технолог** | Управление оборудованием, планирование производства, просмотр истории |
| **Оператор** | Переработка: бревно → шпон → полуфабрикат → фанера, отгрузка на склад |
| **Кладовщик** | Заказ брёвен у поставщиков, просмотр остатков |
